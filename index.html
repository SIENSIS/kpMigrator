Everything is generated in your browser — nothing is sent anywhere. Your project is saved automatically in this browser. Built on CodeIgniter 4.7 Database Forge · Source code and download on GitHub

Import from SQL

Paste one or more MySQL/MariaDB CREATE TABLE statements. To import an existing table run SHOW CREATE TABLE your_table; (or export the structure from phpMyAdmin / your SQL client) and paste the result. Imported tables are added to the project; a table with the same name is replaced.
